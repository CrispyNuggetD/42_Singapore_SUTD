TERMINAL ESSENTIALS

tmux quick guide

Hide your terminals. Keep work running. Return later.

Prefix = press Ctrl + B, release both, then press the next key.

1 · What the green bar means

You are inside tmux. Its background server keeps your terminals running when you detach. The bar lists your windows.

Session “daily” = your workspace
  Window 0: Codex   ← a tmux window is like a tab
  Window 1: Shell
  Window 2: Server
A pane is a split within a window, with its own terminal.

2 · Start and return

From an ordinary terminal:

tmux new -A -s daily

Reconnect to daily, or create it if absent.

Already typed plain tmux? Name that session from its shell:

tmux rename-session daily

Use an unused name. List sessions: tmux ls.

3 · Make three windows

  1. Run codex in the first window.
  2. Prefix → c: second shell.
  3. Prefix → c: third shell.
  4. Prefix → w: choose a window.

Switching away hides Codex; it keeps running.

Prefix → d detaches everything. Then close the desktop terminal window.

5 · Close for real

Quit the program normally, then type exit at the shell prompt. This closes its pane; the final pane closes its window.

Ctrl + C stops many foreground commands. It does not detach.

Force-closing with Prefix → x can lose unsaved work.

6 · Codex scrolling

For future launches, inline mode preserves terminal scrollback:

codex --no-alt-screen

Inside tmux, use Prefix → [ to read retained output. This is not a guaranteed fix for UI banners.

Remember: detached work still uses resources and can edit files. Approval prompts wait for you. Sleep pauses local work; reboot ends processes. Campus logout policies may terminate them too. Avoid starting tmux inside tmux.

Your dailylogin setup

Reload once: source ~/.zshrc. Then use:

CommandPurpose
dailyloginRun the workflow; reuse named tmux windows.
dailytermEnter or return to your daily workspace.
dailywindowsList its windows.
start_codex / start_lan42 / start_mailboxLaunch independently; reuse a running window.
stayon / stayon stopStart or stop Stayon; respects its existing controls.

These helpers work outside tmux too. Chrome is skipped when running; VS Code reuses a window. Managed app windows retain output after stopping: rerun the helper to restart, or use Prefix → x to remove the window.
